# Ember 1.0

First release. A small, text-only desktop widget for Windows 10/11 that shows only what is relevant: CPU (hot cores), network, GPU, memory, disk, Claude / Codex / Copilot usage limits and device batteries, plus markdown sticky notes.

## Download

- `Ember-v1.0-win-x64.exe`: the program (one file, self-contained).
- `Ember-v1.0-win-x64.zip`: the program with `install.ps1` / `uninstall.ps1` (start at logon, Start menu shortcut).

## Highlights

- Lines show only when a value crosses its threshold (with delays and threshold bands), and keep their space for a while, so the widget seldom resizes.
- btop-style braille graphs, usage bars, 20 themes, backgrounds (acrylic, blur, glass, gradient, panel, solid), row backgrounds, header styles and icons.
- Top processes under the lines they belong to; process details window (copyable), file properties, end process.
- Claude, Codex and Copilot usage with reset time and projection.
- Bluetooth and Razer receiver batteries.
- Network ping and optional traceroute.
- Settings window, JSON import/export of themes and layouts, debug log with an extended decision log.

## Notes

- CPU temperatures need admin rights (LibreHardwareMonitor): start elevated or use "Start at logon".
- Built and tested on Linux and GitHub Actions; see "Not tested" in the README.
