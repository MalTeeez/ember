# Ember 1.2

- Usage projection of the weekly window uses the recent pace (the last 24 h of Ember's own samples, kept across restarts; at least 12 h needed), not the average since the week started. A heavy start of the week no longer makes the "empty … before reset" estimate too early. The wording is as before 1.1; hover the line for the run-out time, the reset and the pace used.
- New option (Appearance → Row backgrounds): band behind the toolbar (top line).
