# Ember 1.1

- Usage projection shows when the limit is reached at the current pace, as a local time ("⚠ empty Sat 16:00"), like the Claude website. Hover the line for the details (date, time before the reset, how the pace is measured).
- Sub-lines (processes, adapters, traceroute hops) are drawn as a tree: "├" for each sub-line, "└" for the last one.
