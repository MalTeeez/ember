# Ember 1.5

- **Desktop tools no longer break:** the widget and notes are no longer owned by the desktop unless you turn on Settings → General → **Keep on the desktop**. This fixes QuickLook (and similar tools) not working while Ember runs. With the option off, "Show desktop" (Win+D) also hides Ember.
- **Subscription shown** next to the provider name: "claude max", "codex pro", "copilot business" (from the credentials file, Codex `plan_type`, Copilot `copilot_plan`).
- **Claude token found in more places:** `CLAUDE_CONFIG_DIR`, `~/.claude` (CLI), and `%APPDATA%\Claude` / `%LOCALAPPDATA%\Claude` (desktop app).
- **New bar style "fine":** a braille bar that uses both dot columns per character, for twice the detail (Appearance → Usage bar style).
- **Device names:** a device with an unknown kind now keeps its real name instead of showing a bare "device".
