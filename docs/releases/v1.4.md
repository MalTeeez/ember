# Ember 1.4

- **Install from the app:** Settings → General → Install (start at logon). Windows asks for admin once. Ember copies itself to %LOCALAPPDATA%\Ember, starts at each logon with admin rights, and restarts from there. Starting a newer exe offers to update the install. Uninstall is in the same place. The PowerShell scripts are removed; the release has only the exe.
- **Network rates only with unusual traffic** (the last ~10 s at least 4 × the 30 min average, and at least 20 Mbit/s down or 5 Mbit/s up; set in Thresholds). Option "Network rates always" in Layout → Fields.
- **Usage lines stay** on network errors, timeouts, HTTP 5xx and 429: Ember keeps the last values and polls less often. The lines are hidden only after 15 min without data, or at once when the token is missing, expired or not accepted.
- **Log:** a new log at each start (the previous one is ember.log.old). Usage failures now log the reason.
